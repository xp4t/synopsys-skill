# Synopsys skill collection

Use [the tool router](skills/synopsys/SKILL.md) for tool selection and
[RTL-to-GDSII orchestration](skills/synopsys-rtl2gds/SKILL.md) for implementation
requests. Each discoverable skill is a separate directory under `skills/`.

Read [README](README.md), [configuration](references/configuration.md) and
[the execution contract](references/execution-contract.md) before a new run.
Installation paths, versions, licenses and technology come from the user's local
configuration. Generated local evidence is private and is not part of this bundle.
